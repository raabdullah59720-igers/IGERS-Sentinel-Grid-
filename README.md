# IGERS-BD-01 — Professional Offline Website

A lightweight, static engineering concept/presentation website for **IGERS-BD-01 — Integrated Gradient-Based Energy Recovery and Storage System**.

## Open locally
1. Extract the ZIP.
2. Open the `IGERS-BD-01` folder.
3. Double-click `index.html`.
4. No server, database, API, package installation or internet connection is required.

## Files
- `index.html` — page structure and editable text.
- `style.css` — visual design, responsive layout and animations.
- `script.js` — mobile navigation and lightweight reveal animations.
- `assets/*.svg` — offline engineering illustrations.

## Replace visuals
Replace an SVG inside `assets/` with another local SVG using the same filename, or update the corresponding `src="assets/..."` in `index.html`. Keep files local to preserve offline operation.

## Edit text
Main project text is directly inside `index.html`. Search for the relevant heading, paragraph or identification field and edit it.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of the `IGERS-BD-01` folder (so `index.html` is at the repository root).
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose the main branch and `/ (root)`.
5. Save. GitHub Pages will publish the static site.

## Engineering / research note
This website deliberately presents IGERS-BD-01 as a research and engineering concept. It does not claim commercial deployment, validated performance, guaranteed energy output or experimental verification.
